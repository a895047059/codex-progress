# Codex Progress Editor

此扩展只在 Codex Progress 发起附加请求并打开本扩展的 Cursor 链接时运行。它读取 Cursor 当前活动文本编辑器中的选区；选区为空时读取该编辑器全文，然后发送到本机 `127.0.0.1` 的 Codex Progress 服务。

扩展不会监听编辑变化、后台扫描工作区或主动查找、读取其他文件中的密钥。附加范围仅限当前活动编辑器的选区或全文；请在触发附加前确认当前内容适合发送。发送内容最多为 60,000 个 Unicode 字符且不超过 100,000 字节 UTF-8；超出部分会截断，并在请求中标记 `truncated: true`。

当前文件需要已保存为本地文件，才能附加绝对路径。
